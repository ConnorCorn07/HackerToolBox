## What is Hash Cat?

Hash cat is a "password recovery tool," also known as a password cracker


## Hash Cat modes:
  - Brute-Force attack
  - Combinator attack
  - Dictionary attack
  - Fingerprint attack
  - Hybrid attack
  - Mask attack
  - Permutation attack
  - Rule-based attack
  - Table-Lookup attack
  - Toggle-Case attack
  - PRINCE attack

Install on any Linux machine using:
  sudo apt install hashcat
